ConectaCruz

Elección de un framework móvil para un negocio local de Santa Cruz

Aplicaciones Móviles I

Problema

Una churrasquería local necesita comenzar con un catálogo móvil. Pedidos y reservas pertenecen a una fase futura.

Pregunta: ¿qué framework conviene con presupuesto limitado y necesidad de Android e iOS?

Alternativas

  • Flutter: una base de código con Dart.
  • React Native: reutilización basada en React con puntos específicos por plataforma.
  • Nativo: herramientas propias de Android y Apple.

Método

Matriz ponderada con escala de 1 a 5.

  • Costo: 30%
  • Rendimiento: 20%
  • Comunidad: 15%
  • Compatibilidad: 25%
  • Curva de aprendizaje: 10%

Los valores son una evaluación justificada, no benchmarks.

Resultados

AlternativaTotal / 100
Flutter91
React Native83
Nativo Android/iOS66

Fórmula: peso × calificación / 5

Elección y demostración

Se propone Flutter para el MVP por una base de código común y un costo inicial contenido.

La app implementa MaterialApp, Scaffold, el título ConectaCruz y el botón Ver negocios, que navega a un catálogo breve.

Limitación: no se ejecutó en un emulador por un bloqueo documentado del entorno Flutter.
