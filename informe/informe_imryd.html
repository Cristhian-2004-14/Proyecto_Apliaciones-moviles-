Elección de un framework móvil para un negocio local de Santa Cruz

Aplicaciones Móviles I · Caso: ConectaCruz y una churrasquería local · 8 de noviembre de 2026

Introducción

Pequeños negocios de Santa Cruz suelen presentar su oferta y atender consultas por WhatsApp y redes sociales. En este caso académico, ConectaCruz requiere una primera aplicación que muestre un catálogo y que en una fase posterior pueda admitir pedidos y reservas. El caso no demuestra que exista hoy una operación digital de pedidos o reservas: se tratan como necesidades futuras. El objetivo fue comparar Flutter, React Native y desarrollo nativo separado para Android e iOS. La evaluación no constituye un benchmark empírico.

Métodos

Se evaluaron costo inicial y de mantenimiento, rendimiento, comunidad y ecosistema, compatibilidad Android/iOS y curva de aprendizaje. La escala fue de 1 a 5, donde 5 favorece el caso. Los pesos suman 100%. Flutter documenta una sola base de código para Android e iOS; React Native permite reutilización con puntos específicos por plataforma; el enfoque nativo usa herramientas oficiales distintas para Android y Apple.

Discusión

Flutter obtiene 91,0/100 y se propone para el MVP por una base de código común, interfaz consistente y costo inicial contenido. Exige aprender Dart y verificar paquetes antes de integrar WhatsApp, pagos, mapas o reservas. React Native puede convenir a un equipo con dominio de React; nativo, para integración específica que justifique dos bases de código. No se realizaron pruebas físicas ni iOS. Flutter recomienda medir rendimiento en un dispositivo real y modo profile. La evidencia local documenta el bloqueo actual del entorno Flutter.
